Initial release of `@notploy/discord`, the official Notploy Community Discord bot. Ships a TypeScript package with a Discord.js client, a slash command registry (`/about`, `/help`, `/docs`, `/links`, `/status`, `/version`), a dedicated slash command registration script, environment-based configuration, an isolated read-only GitHub integration, optional Notploy API access through `@notploy/sdk`, configurable GitHub notification routing, community onboarding roles and a Docker deployment setup.
