Docker networks: create, import, inspect and resynchronise them across servers.

`notploy network` exposes **9 commands**. They map one-to-one onto the `network.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy network --help` to list these commands in your terminal, or
	`notploy network <command> --help` for a single command.
</Callout>

## Commands

### `notploy network all`

Calls `GET /api/trpc/network.all`.

```bash
notploy network all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--serverId <value>` | string | No | — |

### `notploy network create`

Calls `POST /api/trpc/network.create`.

```bash

```

| Option | Type | Required | Allowed values |
