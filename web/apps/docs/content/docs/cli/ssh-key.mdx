SSH keys used to reach servers and clone private repositories.

`notploy ssh-key` exposes **7 commands**. They map one-to-one onto the `ssh-key.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy ssh-key --help` to list these commands in your terminal, or
	`notploy ssh-key <command> --help` for a single command.
</Callout>

## Commands

### `notploy ssh-key all`

Calls `GET /api/trpc/sshKey.all`.

```bash
notploy ssh-key all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |

### `notploy ssh-key create`

Calls `POST /api/trpc/sshKey.create`.

```bash
notploy ssh-key create --name <value> --privateKey <value> --publicKey <value> --organizationId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--name <value>` | string | Yes | — |
| `--description <value>` | string | No | — |
| `--privateKey <value>` | string | Yes | — |
| `--publicKey <value>` | string | Yes | — |
| `--organizationId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
