Inspect deployment history and queues, read deployment logs and kill a running build.

`notploy deployment` exposes **11 commands**. They map one-to-one onto the `deployment.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy deployment --help` to list these commands in your terminal, or
	`notploy deployment <command> --help` for a single command.
</Callout>

## Commands

### `notploy deployment all`

Calls `GET /api/trpc/deployment.all`.

```bash
notploy deployment all --applicationId <value> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--applicationId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
