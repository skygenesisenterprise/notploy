Rebrand the instance: application name, logos, favicon and links.

`notploy whitelabeling` exposes **4 commands**. They map one-to-one onto the `whitelabeling.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy whitelabeling --help` to list these commands in your terminal, or
	`notploy whitelabeling <command> --help` for a single command.
</Callout>

## Commands

### `notploy whitelabeling get`

Calls `GET /api/trpc/whitelabeling.get`.

```bash
notploy whitelabeling get [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |

### `notploy whitelabeling get-public`

Calls `GET /api/trpc/whitelabeling.getPublic`.

```bash
notploy whitelabeling get-public [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |

### `notploy whitelabeling reset`

Calls `POST /api/trpc/whitelabeling.update`.

```bash

```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--whitelabelingConfig <json>` | object | Yes | — |
