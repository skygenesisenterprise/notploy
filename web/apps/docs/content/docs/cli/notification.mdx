Notification channels — Slack, Discord, Telegram, email and others — plus test deliveries.

`notploy notification` exposes **41 commands**. They map one-to-one onto the `notification.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy notification --help` to list these commands in your terminal, or
	`notploy notification <command> --help` for a single command.
</Callout>

## Commands

### `notploy notification all`

Calls `GET /api/trpc/notification.all`.

