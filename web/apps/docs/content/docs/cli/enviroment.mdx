The Notploy CLI can be used to create, deploy, and manage enviroments.

## Requirements

Is required to be already authenticated with the Notploy CLI.


## Commands

1. `notploy env pull <file>` -  Pull environment variables from Notploy in a file.
2. `notploy env push <file>` - Push environment variables to Notploy from a file.
