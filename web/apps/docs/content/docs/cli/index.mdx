description: A guide to using the Notploy command-line interface
---

Notploy CLI is a command-line tool for remotely managing your Notploy server. It simplifies creating, deploying, and managing applications and databases.

## Installation

```bash
npm install -g @notploy/cli
```

## Usage

```bash
notploy COMMAND
```
To get help on a specific command:

```bash
notploy COMMAND --help
```
