The Notploy CLI can be used to create, deploy, and manage applications.

## Requirements

Is required to be already authenticated with the Notploy CLI.


## Commands

1. `notploy app create` - Create a new application.
2. `notploy app delete` - Delete an application.
3. `notploy app deploy` - Deploy an application.
4. `notploy app stop` - Stop a running application.
