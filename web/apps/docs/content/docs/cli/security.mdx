Per-application HTTP basic auth and response security headers.

`notploy security` exposes **4 commands**. They map one-to-one onto the `security.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy security --help` to list these commands in your terminal, or
	`notploy security <command> --help` for a single command.
</Callout>

## Commands

### `notploy security create`

Calls `POST /api/trpc/security.create`.

```bash
notploy security create --applicationId <applicationId> --username <username> --password <password>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--applicationId <value>` | string | Yes | — |
| `--username <value>` | string | Yes | — |
| `--password <value>` | string | Yes | — |
