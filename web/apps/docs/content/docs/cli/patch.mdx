Versioned file overrides applied to an application at deploy time.

`notploy patch` exposes **12 commands**. They map one-to-one onto the `patch.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy patch --help` to list these commands in your terminal, or
	`notploy patch <command> --help` for a single command.
</Callout>

## Commands

### `notploy patch by-entity-id`

Calls `GET /api/trpc/patch.byEntityId`.

```bash
notploy patch by-entity-id --id <id> --type <type>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--id <value>` | string | Yes | — |
| `--type <value>` | string | Yes | `application`, `compose` |
