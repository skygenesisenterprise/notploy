Deploy an authentication proxy in front of applications and manage its domains.

`notploy forward-auth` exposes **10 commands**. They map one-to-one onto the `forward-auth.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy forward-auth --help` to list these commands in your terminal, or
	`notploy forward-auth <command> --help` for a single command.
</Callout>

## Commands

### `notploy forward-auth deploy-on-server`

Calls `POST /api/trpc/forwardAuth.deployOnServer`.

```bash
notploy forward-auth deploy-on-server --serverId <serverId> --providerId <providerId>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--serverId <value>` | string | Yes | — |
| `--providerId <value>` | string | Yes | — |
