Billing for Notploy Cloud: plans, invoices, checkout and the customer portal.

`notploy stripe` exposes **10 commands**. They map one-to-one onto the `stripe.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy stripe --help` to list these commands in your terminal, or
	`notploy stripe <command> --help` for a single command.
</Callout>

## Commands

### `notploy stripe can-create-more-servers`

Calls `GET /api/trpc/stripe.canCreateMoreServers`.

```bash
notploy stripe can-create-more-servers
```

### `notploy stripe create-checkout-session`

Calls `POST /api/trpc/stripe.createCheckoutSession`.

```bash
notploy stripe create-checkout-session --tier <tier> --productId <productId> --serverQuantity <serverQuantity> --isAnnual
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--tier <value>` | string | Yes | `legacy`, `hobby`, `startup` |
| `--productId <value>` | string | Yes | — |
| `--serverQuantity <value>` | number | Yes | — |
| `--isAnnual` | boolean | Yes | — |
