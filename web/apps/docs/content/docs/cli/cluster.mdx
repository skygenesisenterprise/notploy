Add and remove Swarm workers and managers.

`notploy cluster` exposes **4 commands**. They map one-to-one onto the `cluster.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy cluster --help` to list these commands in your terminal, or
	`notploy cluster <command> --help` for a single command.
</Callout>

## Commands

### `notploy cluster add-manager`

Calls `GET /api/trpc/cluster.addManager`.

```bash
notploy cluster add-manager [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--serverId <value>` | string | No | — |
