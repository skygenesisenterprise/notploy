S3-compatible storage destinations that backups are uploaded to.

`notploy destination` exposes **7 commands**. They map one-to-one onto the `destination.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy destination --help` to list these commands in your terminal, or
	`notploy destination <command> --help` for a single command.
</Callout>

## Commands

### `notploy destination all`

Calls `GET /api/trpc/destination.all`.

```bash
notploy destination all [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--profile <name>` | string | No | — |
