GitLab connections, plus branch and repository lookups.

`notploy gitlab` exposes **7 commands**. They map one-to-one onto the `gitlab.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy gitlab --help` to list these commands in your terminal, or
	`notploy gitlab <command> --help` for a single command.
</Callout>

## Commands

### `notploy gitlab create`

Calls `POST /api/trpc/gitlab.create`.

```bash
notploy gitlab create --authId <authId> --name <name> --gitlabUrl <gitlabUrl> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--applicationId <value>` | string | No | — |
| `--secret <value>` | string | No | — |
| `--groupName <value>` | string | No | — |
| `--gitProviderId <value>` | string | No | — |
| `--redirectUri <value>` | string | No | — |
| `--authId <value>` | string | Yes | — |
| `--name <value>` | string | Yes | — |
| `--gitlabUrl <value>` | string | Yes | — |
| `--gitlabInternalUrl <value>` | string | No | — |
