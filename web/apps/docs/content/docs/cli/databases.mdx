title: Databases
description: A guide to using the Notploy CLI to manage databases
---

The Notploy CLI can be used to create, deploy, and manage databases.

## Requirements

Is required to be already authenticated with the Notploy CLI.


## Commands

### MariaDB 

1. `notploy database mariadb create` - Create a new mariadb database.
2. `notploy database mariadb delete` - Delete an mariadb database.
3. `notploy database mariadb deploy` - Deploy a mariadb database.
4. `notploy database mariadb stop` - Stop a running mariadb database.
