Label projects and filter the dashboard by tag.

`notploy tag` exposes **8 commands**. They map one-to-one onto the `tag.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy tag --help` to list these commands in your terminal, or
	`notploy tag <command> --help` for a single command.
</Callout>

## Commands

### `notploy tag all`

Calls `GET /api/trpc/tag.all`.

```bash
notploy tag all
```

### `notploy tag assign-to-project`

Calls `POST /api/trpc/tag.assignToProject`.

```bash
notploy tag assign-to-project --projectId <projectId> --tagId <tagId>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--projectId <value>` | string | Yes | — |
| `--tagId <value>` | string | Yes | — |
