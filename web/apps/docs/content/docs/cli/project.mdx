Create, update, search and remove projects, and read the onboarding state of an instance.

`notploy project` exposes **11 commands**. They map one-to-one onto the `project.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy project --help` to list these commands in your terminal, or
	`notploy project <command> --help` for a single command.
</Callout>

## Commands

### `notploy project all`

Calls `GET /api/trpc/project.all`.

```bash
notploy project all
```

### `notploy project all-for-permissions`

Calls `GET /api/trpc/project.allForPermissions`.

```bash
notploy project all-for-permissions
```

### `notploy project complete-onboarding`

Calls `POST /api/trpc/project.completeOnboarding`.

```bash
notploy project complete-onboarding
```

### `notploy project create`

Calls `POST /api/trpc/project.create`.

```bash
notploy project create --name <name> [options]
```

| `--name <value>` | string | Yes | — |

| `--env <value>` | string | No | — |
