Accounts, API keys, sessions, permissions and per-user metrics.

`notploy user` exposes **26 commands**. They map one-to-one onto the `user.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy user --help` to list these commands in your terminal, or
	`notploy user <command> --help` for a single command.
</Callout>

## Commands

### `notploy user all`

Calls `GET /api/trpc/user.all`.

```bash

```
