Attach domains to applications and Compose stacks, and generate or validate them.

`notploy domain` exposes **11 commands**. They map one-to-one onto the `domain.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy domain --help` to list these commands in your terminal, or
	`notploy domain <command> --help` for a single command.
</Callout>
