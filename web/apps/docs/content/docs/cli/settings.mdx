Instance-wide settings: Traefik, Docker cleanup, monitoring, GPUs, updates and SSH.

`notploy settings` exposes **57 commands**. They map one-to-one onto the `settings.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy settings --help` to list these commands in your terminal, or
	`notploy settings <command> --help` for a single command.
</Callout>

## Commands

### `notploy settings assign-domain-server`

```bash
notploy settings assign-domain-server --host <value> [options]
```

| `--no-https` | boolean | No | — |
