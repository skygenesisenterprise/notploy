Zones and records for connected DNS providers such as Cloudflare and Route 53.

`notploy dns-provider` exposes **11 commands**. They map one-to-one onto the `dns-provider.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy dns-provider --help` to list these commands in your terminal, or
	`notploy dns-provider <command> --help` for a single command.
</Callout>

## Commands

### `notploy dns-provider all`

Calls `GET /api/trpc/dnsProvider.all`.

```bash
notploy dns-provider all
```

### `notploy dns-provider create`

Calls `POST /api/trpc/dnsProvider.create`.

```bash
notploy dns-provider create --name <name> --config <config>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--name <value>` | string | Yes | — |
| `--config <value>` | string | Yes | — |

### `notploy dns-provider create-record`

Calls `POST /api/trpc/dnsProvider.createRecord`.

```bash

```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
