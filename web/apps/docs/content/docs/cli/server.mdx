Add remote servers over SSH, validate them and read their metrics and services.

`notploy server` exposes **19 commands**. They map one-to-one onto the `server.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy server --help` to list these commands in your terminal, or
	`notploy server <command> --help` for a single command.
</Callout>

## Commands

```bash
notploy server all
```

### `notploy server create`

Calls `POST /api/trpc/server.create`.

```bash
notploy server create --name <name> --description <description> --ipAddress <ipAddress> --port <port> --username <username> --sshKeyId <sshKeyId> --serverType <serverType> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--name <value>` | string | Yes | — |
| `--description <value>` | string | Yes | — |
| `--ipAddress <value>` | string | Yes | — |
| `--port <value>` | number | Yes | — |
| `--username <value>` | string | Yes | — |
| `--sshKeyId <value>` | string | Yes | — |
| `--serverType <value>` | string | Yes | `deploy`, `build` |
| `--enableDockerCleanup` | boolean | No | — |
