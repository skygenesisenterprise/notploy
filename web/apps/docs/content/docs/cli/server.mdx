Add remote servers over SSH, validate them and read their metrics and services.

`notploy server` exposes **21 commands**. They map one-to-one onto the `server.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy server --help` to list these commands in your terminal, or
	`notploy server <command> --help` for a single command.
</Callout>
