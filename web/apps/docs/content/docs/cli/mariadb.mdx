Provision and operate MariaDB databases, including backups and external ports.

`notploy mariadb` exposes **16 commands**. They map one-to-one onto the `mariadb.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy mariadb --help` to list these commands in your terminal, or
	`notploy mariadb <command> --help` for a single command.
</Callout>
