Inspect volumes, their size and the files inside them.

`notploy docker-volume` exposes **8 commands**. They map one-to-one onto the `docker-volume.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy docker-volume --help` to list these commands in your terminal, or
	`notploy docker-volume <command> --help` for a single command.
</Callout>

## Commands
