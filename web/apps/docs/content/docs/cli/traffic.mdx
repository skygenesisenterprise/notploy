Traffic sources and properties, HTTP reports and the audience overview built from access logs.

`notploy traffic` exposes **11 commands**. They map one-to-one onto the `traffic.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy traffic --help` to list these commands in your terminal, or
	`notploy traffic <command> --help` for a single command.
</Callout>

## Commands

### `notploy traffic audience`

Calls `GET /api/trpc/traffic.audience`.

```bash
notploy traffic audience [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--preset <value>` | string | No | `1h`, `24h`, `7d`, `30d`, `custom` |
| `--from <value>` | string | No | — |
| `--to <value>` | string | No | — |
| `--propertyIds <json>` | array | No | — |
| `--platform <value>` | string | No | — |
| `--limit <value>` | number | No | — |
| `--profile <name>` | string | No | — |
