Inspect Docker Swarm nodes, node workloads and container statistics.

`notploy swarm` exposes **4 commands**. They map one-to-one onto the `swarm.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy swarm --help` to list these commands in your terminal, or
	`notploy swarm <command> --help` for a single command.
</Callout>

## Commands

### `notploy swarm get-container-stats`

Calls `GET /api/trpc/swarm.getContainerStats`.

```bash
notploy swarm get-container-stats [options]
```
