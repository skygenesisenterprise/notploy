GitHub app connections, plus branch and repository lookups.

`notploy github` exposes **6 commands**. They map one-to-one onto the `github.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy github --help` to list these commands in your terminal, or
	`notploy github <command> --help` for a single command.
</Callout>

## Commands

### `notploy github get-github-branches`

Calls `GET /api/trpc/github.getGithubBranches`.

```bash
notploy github get-github-branches --repo <repo> --owner <owner> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--repo <value>` | string | Yes | — |
| `--owner <value>` | string | Yes | — |
| `--githubId <value>` | string | No | — |
