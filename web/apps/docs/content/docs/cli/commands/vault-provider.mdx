External secret managers connected to the platform to resolve secrets at deploy time.

`notploy vault-provider` exposes **7 commands**. They map one-to-one onto the `vault-provider.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy vault-provider --help` to list these commands in your terminal, or
	`notploy vault-provider <command> --help` for a single command.
</Callout>

## Commands

### `notploy vault-provider all`

Calls `GET /api/trpc/vaultProvider.all`.

```bash
notploy vault-provider all
```

### `notploy vault-provider create`

Calls `POST /api/trpc/vaultProvider.create`.

```bash
notploy vault-provider create --name <name> --config <config> --assignments <assignments>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--name <value>` | string | Yes | — |
| `--config <value>` | string | Yes | — |
| `--assignments <value>` | string | Yes | — |
