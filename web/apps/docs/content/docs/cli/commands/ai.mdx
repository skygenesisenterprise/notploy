AI providers and models, plus log analysis and configuration suggestions.

`notploy ai` exposes **14 commands**. They map one-to-one onto the `ai.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy ai --help` to list these commands in your terminal, or
	`notploy ai <command> --help` for a single command.
</Callout>

## Commands

### `notploy ai analyze-logs`

Calls `POST /api/trpc/ai.analyzeLogs`.

```bash
notploy ai analyze-logs --aiId <aiId> --logs <logs> --context <context>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--aiId <value>` | string | Yes | — |
| `--logs <value>` | string | Yes | — |
| `--context <value>` | string | Yes | `build`, `runtime` |
