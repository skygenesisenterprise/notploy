Organizations, members, invitations and the active organization.

`notploy organization` exposes **11 commands**. They map one-to-one onto the `organization.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy organization --help` to list these commands in your terminal, or
	`notploy organization <command> --help` for a single command.
</Callout>

## Commands

### `notploy organization active`

Calls `GET /api/trpc/organization.active`.

```bash
notploy organization active
```
