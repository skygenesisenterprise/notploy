Container registries used to pull private images.

`notploy registry` exposes **7 commands**. They map one-to-one onto the `registry.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy registry --help` to list these commands in your terminal, or
	`notploy registry <command> --help` for a single command.
</Callout>

## Commands

### `notploy registry all`

Calls `GET /api/trpc/registry.all`.

```bash
notploy registry all
```

### `notploy registry create`

Calls `POST /api/trpc/registry.create`.

```bash
notploy registry create --registryName <registryName> --username <username> --password <password> --registryUrl <registryUrl> --registryType <registryType> --imagePrefix <imagePrefix> [options]
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--registryName <value>` | string | Yes | — |
| `--username <value>` | string | Yes | — |
| `--password <value>` | string | Yes | — |
| `--registryUrl <value>` | string | Yes | — |
| `--registryType <value>` | string | Yes | `cloud` |
| `--imagePrefix <value>` | string | Yes | — |
| `--serverId <value>` | string | No | — |
