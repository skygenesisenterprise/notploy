Provision and operate libSQL (SQLite-compatible) databases.

`notploy libsql` exposes **14 commands**. They map one-to-one onto the `libsql.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy libsql --help` to list these commands in your terminal, or
	`notploy libsql <command> --help` for a single command.
</Callout>
