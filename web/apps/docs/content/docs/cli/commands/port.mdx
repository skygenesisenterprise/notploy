Publish container ports directly, without routing them through a domain.

`notploy port` exposes **4 commands**. They map one-to-one onto the `port.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy port --help` to list these commands in your terminal, or
	`notploy port <command> --help` for a single command.
</Callout>

## Commands

### `notploy port create`

Calls `POST /api/trpc/port.create`.

```bash
notploy port create --publishedPort <publishedPort> --publishMode <publishMode> --targetPort <targetPort> --protocol <protocol> --applicationId <applicationId>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--publishedPort <value>` | number | Yes | — |
| `--publishMode <value>` | string | Yes | `ingress`, `host` |
| `--targetPort <value>` | number | Yes | — |
| `--protocol <value>` | string | Yes | `tcp`, `udp` |
| `--applicationId <value>` | string | Yes | — |
