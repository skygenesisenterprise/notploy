Organization roles built from a set of permission statements.

`notploy custom-role` exposes **6 commands**. They map one-to-one onto the `custom-role.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy custom-role --help` to list these commands in your terminal, or
	`notploy custom-role <command> --help` for a single command.
</Callout>

## Commands

### `notploy custom-role all`

Calls `GET /api/trpc/customRole.all`.

```bash
notploy custom-role all
```

### `notploy custom-role create`

Calls `POST /api/trpc/customRole.create`.

```bash
notploy custom-role create --roleName <roleName> --permissions <permissions>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--roleName <value>` | string | Yes | — |
| `--permissions <value>` | string | Yes | — |

### `notploy custom-role get-statements`

```bash
notploy custom-role get-statements
```
