Aggregated counters for the dashboard: services, backups and domains.

`notploy overview` exposes **3 commands**. They map one-to-one onto the `overview.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy overview --help` to list these commands in your terminal, or
	`notploy overview <command> --help` for a single command.
</Callout>

## Commands

### `notploy overview backups`

Calls `GET /api/trpc/overview.backups`.

```bash
notploy overview backups
```

### `notploy overview domains`

Calls `GET /api/trpc/overview.domains`.

```bash
notploy overview domains
```

### `notploy overview services`

Calls `GET /api/trpc/overview.services`.

```bash
notploy overview services
```
