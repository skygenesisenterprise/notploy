SCIM provisioning providers and tokens used for directory sync.

`notploy scim` exposes **3 commands**. They map one-to-one onto the `scim.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy scim --help` to list these commands in your terminal, or
	`notploy scim <command> --help` for a single command.
</Callout>

## Commands

### `notploy scim delete-provider`

Calls `POST /api/trpc/scim.deleteProvider`.

```bash
notploy scim delete-provider --providerId <providerId>
```
