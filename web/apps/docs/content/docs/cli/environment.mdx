Applications and databases live inside an environment, and environments belong to a project.

`notploy environment` exposes **7 commands**. They map one-to-one onto the `environment.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy environment --help` to list these commands in your terminal, or
	`notploy environment <command> --help` for a single command.
</Callout>

## Commands

### `notploy environment by-project-id`

Calls `GET /api/trpc/environment.byProjectId`.

```bash
notploy environment by-project-id --projectId <projectId>
```

| Option | Type | Required | Allowed values |
| --- | --- | --- | --- |
| `--projectId <value>` | string | Yes | — |
