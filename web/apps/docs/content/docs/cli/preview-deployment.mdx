Per-branch deployments created when preview deployments are enabled.

`notploy preview-deployment` exposes **4 commands**. They map one-to-one onto the `preview-deployment.*` API operations, so anything reachable from the dashboard is reachable from here.

<Callout>
	Run `notploy preview-deployment --help` to list these commands in your terminal, or
	`notploy preview-deployment <command> --help` for a single command.
</Callout>

## Commands

### `notploy preview-deployment all`

Calls `GET /api/trpc/previewDeployment.all`.

```bash
notploy preview-deployment all --applicationId <value> [options]
```

| --- | --- | --- | --- |
| `--applicationId <value>` | string | Yes | — |
| `--profile <name>` | string | No | — |
