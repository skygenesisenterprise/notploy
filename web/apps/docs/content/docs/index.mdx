Welcome to the Notploy documentation. Notploy is an open-source, self-hostable platform for deploying and operating applications, databases and Docker Compose stacks on servers you own.

Start with **Discover** to understand the model, follow **Get started** for a guided path to your first deployment, then use the remaining sections as reference for the work you do.
