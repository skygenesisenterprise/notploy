---
title: Goodies
description: "Notploy has certain goodies that are external that can be used with Notploy."
---

1. **Ansible Notploy**: Ansible role to deploy Notploy [Ansible Role](https://github.com/jacobtipp/ansible-notploy)
2. **Notploy Oracle infrastructure**: Deploy Notploy on Oracle infrastructure [Github](https://github.com/statickidz/notploy-oci-free)
3. **Notploy Deploy Action 1**: Automatic Notploy deployments on Github [Github](https://github.com/benbristow/notploy-deploy-action)
4. **Notploy Deploy Action 2**: Automatic Notploy deployments on Github [Github](https://github.com/jmischler72/notploy-deploy-action)
5. **Notploy Deploy Action 3**: Automatic Notploy deployments on Github (Support both `application` and `compose` deployment) [Github](https://github.com/nhridoy/notploy-deploy-action)
5. **Notploy JS Sdk**: Notploy JS SDK [Github](https://github.com/quiint/notploy.js)
6. **Templates Collection** : Docker compose collection for Notploy [Github](https://github.com/benbristow/notploy-compose-templates)
7. **Notploy Port Updater**: Notploy Port Updater [Github](https://github.com/clockradios/notploy-port-updater)
8. **Dokli TUI**: Dokli TUI [Github](https://github.com/jonykalavera/dokli)
10. **nix-notploy**: A NixOS module that runs Notploy using declarative systemd units [Github](https://github.com/el-kurto/nix-notploy)

Want to submit your own? [Submit a PR](https://github.com/Notploy/website/blob/main/README.md)
