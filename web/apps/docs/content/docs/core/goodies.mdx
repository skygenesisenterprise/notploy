---
title: Goodies
description: "Notploy has certain goodies that are external that can be used with Notploy."
---

1. **Ansible Notploy**: Ansible role to deploy Notploy [Ansible Role](https://github.com/jacobtipp/ansible-dokploy)
2. **Notploy Oracle infrastructure**: Deploy Notploy on Oracle infrastructure [Github](https://github.com/statickidz/dokploy-oci-free)
3. **Notploy Deploy Action 1**: Automatic Notploy deployments on Github [Github](https://github.com/benbristow/dokploy-deploy-action)
4. **Notploy Deploy Action 2**: Automatic Notploy deployments on Github [Github](https://github.com/jmischler72/dokploy-deploy-action)
5. **Notploy Deploy Action 3**: Automatic Notploy deployments on Github (Support both `application` and `compose` deployment) [Github](https://github.com/nhridoy/dokploy-deploy-action)
5. **Notploy JS Sdk**: Notploy JS SDK [Github](https://github.com/quiint/dokploy.js)
6. **Templates Collection** : Docker compose collection for Notploy [Github](https://github.com/benbristow/dokploy-compose-templates)
7. **Notploy Port Updater**: Notploy Port Updater [Github](https://github.com/clockradios/dokploy-port-updater)
8. **Dokli TUI**: Dokli TUI [Github](https://github.com/jonykalavera/dokli)
10. **nix-notploy**: A NixOS module that runs Notploy using declarative systemd units [Github](https://github.com/el-kurto/nix-dokploy)

Want to submit your own? [Submit a PR](https://github.com/skygenesisenterprise/notploy/blob/master/README.md)
