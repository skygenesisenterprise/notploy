Sign in

Generate a key in the dashboard under Settings → API Keys, then paste it for the selected instance. Keys are stored only in this browser (chrome.storage.local), never synced or logged.

Security

  • Permissions: storage only. Network access is granted per instance via optional host permissions.
  • No content scripts, no history or page-content collection.
  • Tokens live in chrome.storage.local — convenient, not a vault. Sign out on shared machines.
